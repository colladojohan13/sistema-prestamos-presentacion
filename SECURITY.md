# Seguridad y privacidad

Este repositorio no contiene el código fuente del producto, credenciales, bases de datos, copias de seguridad ni información de clientes.

No publiques aquí:

- Archivos `.env` o claves de acceso.
- Bases de datos SQLite o exportaciones de PostgreSQL.
- Contratos, pagarés, recibos o firmas reales.
- Logos o documentos privados de clientes.
- Copias de seguridad, registros o archivos de producción.

Los asuntos de seguridad deben comunicarse de forma privada al propietario del proyecto y no mediante una incidencia pública.
